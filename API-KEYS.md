# API Keys

All keys are stored locally in your browser (IndexedDB). Nothing is sent to any server.

## AI Provider (required — pick one)

| Provider | Get Key | Used For |
|----------|---------|----------|
| Gemini (Google) | https://aistudio.google.com/apikey | Video spec generation (free tier) |
| Claude (Anthropic) | https://console.anthropic.com/settings/keys | Video spec generation |
| OpenAI | https://platform.openai.com/api-keys | Video spec generation |
| OpenRouter | https://openrouter.ai/keys | Video spec generation (multi-model gateway) |
| Cerebras | https://cloud.cerebras.ai/ | Video spec generation (fast inference) |

## Media Services (optional)

| Service | Get Key | Used For |
|---------|---------|----------|
| ElevenLabs | https://elevenlabs.io/app/settings/api-keys | Voice narration & sound effects |
| Replicate | https://replicate.com/account/api-tokens | AI image/video generation & music |
| FAL.ai | https://fal.ai/dashboard/keys | Fast AI inference (image/video) |
| Pexels | https://www.pexels.com/api/new/ | Stock video & photos |
| Beatoven.ai | https://www.beatoven.ai/pricing | AI music composition |

## Quick Start

1. Get a **Gemini** API key for free at https://aistudio.google.com/apikey (or any AI provider above)
2. Open DraftCut, click the **gear icon** next to "Generate Video Draft"
3. Paste your key in the **AI Provider** tab
4. (Optional) Add media service keys in the **Media Services** tab for richer output
